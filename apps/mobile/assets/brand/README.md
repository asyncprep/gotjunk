# Brand assets

Add the official 1-800-GOT-JUNK? logo here as `logo.png` (white or reversed version, for the
blue header; about 3× its on-screen height of 28 px, so ~84 px tall). Use the file from the
franchise brand kit; don't recreate it.

When `logo.png` is present the app shows it; otherwise it shows the typed wordmark.
The launcher icon is generated from `icon.png` and `icon_foreground.png`
(`dart run flutter_launcher_icons`).
